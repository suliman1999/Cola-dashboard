## 📊 Overview
This project presents an interactive **Power BI Sales Dashboard** analyzing Coca-Cola beverage sales performance across the United States.  
It provides insights into **total sales, units sold, operating profit, margins**, and **geographic distribution** to support data-driven business decisions.

---

## 🎯 Objectives
- Analyze total sales and units sold by beverage brand
- Monitor operating profit and operating margin
- Identify key factors influencing operating profit
- Explore sales distribution across US states
- Support business and strategic decision-making

---

## 🚀 Key Features
- Sales and profit KPIs by beverage brand
- Interactive table with sales, units sold, pricing, and margins
- Operating profit analysis using **Key Influencers**
- Sales visualization by US state (map)
- Date range slicer for time-based analysis
- AI-powered insights through Power BI analytics features
